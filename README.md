# 🌦️ Weather Wizard

A sleek and responsive weather app that shows real-time weather information using a public Weather API. Built using HTML, CSS, and JavaScript.

---

## 🚀 Features

- 🌍 Get current weather by city name  
- 🌡️ Displays temperature, weather condition, humidity, and wind speed  
- 📱 Fully responsive design  
- ⚡ Built with vanilla JavaScript and Fetch API  

---

## 🛠️ Tech Stack

- **HTML5** – Page structure  
- **CSS3** – Styling and responsiveness  
- **JavaScript** – Logic and API handling  
- **Weather API** – (e.g. [OpenWeatherMap](https://openweathermap.org/)) for live weather data
